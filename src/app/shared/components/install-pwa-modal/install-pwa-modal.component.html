Instalar Amamanta en iPhone

Sigue estos pasos para añadir la aplicación a tu pantalla de inicio.

  1. 1

    Pulsa el botón Compartir de Safari.

  2. 2

    Selecciona Añadir a pantalla de inicio.

  3. 3

    Pulsa Añadir para terminar.

En iPhone debes abrir la aplicación desde Safari para poder instalarla.
